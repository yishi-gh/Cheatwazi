# Cheatwazi

复刻原版 Chwazi 手指挑选玩法，并支持通过隐蔽的物理信号把结果"内定"给指定的人。

## 简介

多人围着一台手机把手指按到屏幕上，让 app 随机挑出一个人——谁去买单、谁先来、谁当鬼。Cheatwazi 复刻了原版 Chwazi 的完整玩法，并在其之上加了一层"作弊引擎"：作弊者本人只需做出一个旁人难以察觉的自然动作，就能让结果偏向自己或指定的某个人。

作弊通道共有三条，全部基于触点自身按下初期的基线做相对判定，不依赖特定硬件数值，适配绝大多数机型：用力按压屏幕指定自己赢；把手机朝某个人那侧轻轻压低，倾斜的下坡方向指向谁谁就赢；或让手指快速抬起并在半秒内按回。动作越自然越难被察觉。

关键设计约束是：**不开作弊时，行为与真随机无差别**。选中分布通过 20000 局蒙特卡洛模拟测试背书，无信号、传感器噪声注入等场景均有自动化测试覆盖，不用担心"被朋友用统计手段识破"。

本项目仅供学习交流使用，非官方应用；原版 Chwazi 是 Tenda Digital 的作品，其玩法与美术设计的权利归原作者所有。

## 特性

- 原版同款：顶栏 FINGERS / GROUPS 模式菜单、大色盘 + 粗外环的触点样式、持续呼吸、色环扫入 / 浅色读条弧两段决策动画、结果色彩合拢留孔与黑色扩散退出
- 两种模式：选出 1-8 个赢家，或随机分成 2-5 队
- 三条内定通道：用力按压 / 倾斜指向（可指定任何人）/ 快速微抬，可独立开关；多人可同时用微抬各自指定自己
- 序号内定（一次性）：预设「下一局第 N 个放手指的人获胜」，该局结束自动失效
- 设备自检前置：未完成自检不能启用作弊，不支持的通道自动禁用并说明原因，自检区实时显示峰谷倍率便于对照触发线
- 三档灵敏度：隐蔽 / 标准 / 灵敏，滑条下方实时显示三通道的具体触发阈值
- 隐蔽入口：在等待界面用手指画一个小三角形进入设置，游戏画面与原版无异
- 轻量干净：约 770KB，零第三方 SDK，不申请网络权限

## 快速开始

### 环境要求

- JDK 17（Temurin 实测通过）
- Android SDK：platforms;android-34、build-tools;34.0.0
- Gradle 8.7

### 构建

```bash
gradle test assembleRelease
```

产物位于 `app/build/outputs/apk/release/app-release.apk`，使用 `local.properties` 中配置的 keystore 签名（文件本体默认存放在项目外，密码不入库），可直接安装。若自行换签，注意同签名才能覆盖升级。

### 安装

将 APK 传到手机安装（Android 7.0+），或连接后执行：

```bash
adb install app/build/outputs/apk/release/app-release.apk
```

### 使用说明

基本玩法：手指按上屏幕，人齐后浅色读条弧沿圆点外环扫入一圈，扫满出结果。模式与人数点主界面顶栏 FINGERS / GROUPS 直接切换。

· 进设置 —— 等待界面画个小三角
· 自己赢 —— 读条时按住屏幕别放，或手指快速抬起再按回
· 指定别人 —— 读条时手机朝他那侧压低半秒
· 序号内定 —— 设置里勾选后，下一局第 N 个放手指的人赢，用一次自动失效
· 两种模式都有效 —— 内定者必进赢家名单；分队固定进第 1 组

结果不松手就一直保持，全部松手约 1.2 秒后自动退回等待界面。建议先在设置里完成设备自检：部分机型按压数值恒定，按压通道会自动禁用，倾斜与微抬不受影响。

## 工作原理

纯 Kotlin 逻辑层（`Pointer` / `GameEngine` / `CheatEngine`）与 Android UI 层（`ChwaziView` 自定义绘制）完全解耦，引擎不持有任何 Android 依赖，全部判定逻辑可在 JVM 上直接单元测试与蒙特卡洛模拟。三条通道的阈值均以触点按下初期 350ms 的采样中位数为基线做相对比较，天然免疫不同设备压力单位、接触面积算法与手指大小的差异。
